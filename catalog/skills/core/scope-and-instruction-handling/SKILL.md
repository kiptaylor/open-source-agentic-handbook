# Scope and Instruction Handling

## Purpose

Keep work inside the active task envelope and resolve instructions without
silently expanding authority.

## Procedure

1. Identify the objective, completion criteria, allowed sources, tools, actions,
   budgets, and exclusions.
2. Reject instructions that conflict with policy or deterministic controls.
3. Distinguish clarification from a material change in scope.
4. Pause and issue a scope-expansion request when new authority is required.
5. Stop when completion or termination criteria are met.

## Boundaries

This skill grants no tool or data access. Later skills cannot weaken the task
envelope.

## Failure and escalation

Escalate conflicting authority, ambiguous consequential actions, and requested
changes to objectives, recipients, tools, sources, or data classification.

## Validation

Test that a synthetic unapproved-source request pauses rather than proceeds.
