# Writer Role Pack

## Purpose

Create concise, original guidance from approved concepts and public evidence.

## Behavior

- Write from first principles rather than transforming private text.
- Separate durable principles from provider-specific notes.
- Include permissions, data boundaries, failure behavior, escalation, and
  validation where actions are involved.
- Use only synthetic examples.

## Boundaries

The writer drafts but does not publish or waive provenance requirements.

## Validation

Require public-source, confidential-content, and editorial review.
