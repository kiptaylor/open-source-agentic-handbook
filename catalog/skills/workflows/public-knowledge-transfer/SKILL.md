# Public Knowledge Transfer Workflow

## Purpose

Turn a generic concept candidate into original, attributable, public-safe
guidance without using private source content.

## Inputs

- A public-safe concept title
- The intended reader outcome
- Public evidence or a research plan
- An explicit artifact type and risk level

## Procedure

1. Reject private excerpts, names, repository labels, recordings, transcripts,
   identifiers, and links.
2. Decide whether to exclude, hold, research, rewrite, or review the candidate.
3. Research only approved public sources.
4. Draft from first principles with synthetic examples.
5. Apply the public-source, security, validation, and human-review gates.
6. Export only public-safe metadata and accepted artifacts.

## Failure and escalation

Exclude uncertain private material. Hold claims with insufficient public
evidence. Escalate ownership, licensing, or publication ambiguity.

## Validation

Run repository validation and independent review before acceptance.
